# Exp009：数据质量门槛会不会改变药物排名？

## 简要说明

按 LINCS 签名重复实验的一致性筛选数据，比较严格或宽松的质量门槛对药物排名的影响，并检查 Broad 发布的 TAS 分数。剂量和时间条件始终分别保留。

## 结果

通过稳定 ID 合并后，共得到 11,850 条 MCF7 化学扰动、24 小时的可评分签名。主筛选使用项目预先设定的 CC≥0.2；CC≥0.1、CC≥0.3 和额外的 TAS≥0.2 仅用于敏感性比较。签名数和药物数见 `qc_threshold_comparison.csv`；分布见 `lincs_metric_audit.csv` 和图表。`metadata_join_sensitivity.csv` 对比了历史上把药物显示名称也作为连接条件的做法；名称拼写差异会漏掉本可通过稳定 ID 匹配的签名。

## CC 与 TAS 的区别

`distil_cc_q75` 描述重复签名的一致性，CC≥0.2 是本项目采用的质量过滤值，不是适用于所有研究的通用标准。TAS 是 Broad 定义的另一种综合活动分数。CMap 2017 论文在特定化合物筛选情境中使用 TAS≥0.2，不能把该值当作 CC 阈值。本实验保留 LINCS 发布的 TAS 原值，并只把 TAS≥0.2 作为单独的附加敏感性条件。由于无法确认发布字段 `distil_ss` 等同于官方 TAS 公式中的原始 SS，本实验不重新计算 TAS；审计依据见 `tas_calculation_audit.csv`。

## 剂量与结果边界

结果始终按剂量和时间分别汇总，没有为每种药物挑选“最有利”的剂量作为总分。剂量间方向稳定性见 `dose_direction_stability.csv`，逐剂量药物分数热图见 figures。QC 门槛对排名的影响只能说明筛选结果对输入条件敏感；WTCS 表示表达逆转关联，不能证明细胞杀伤或临床疗效。
