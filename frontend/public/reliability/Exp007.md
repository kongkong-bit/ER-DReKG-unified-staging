# Exp007：S1 基因签名规模对药物排名的影响

## 简要说明

使用同一批 4,761 条历史 LINCS MCF7 药物扰动记录，以六种疾病基因名单重新评分。分数和排名的变化用于评估方法稳定性，不代表临床疗效。

## 方法

WTCS 算法、LINCS 数据、BING 背景和历史正式筛选条件保持一致：24 小时且 `distil_cc_q75≥0.2`。药物按药物 ID、细胞、剂量和时间分组，组内计算 WTCS 中位数；不同剂量和时间不合并。A 方案使用历史 BING 交集（70 个上调、55 个下调）；B_matched125 为 70/55；B100、B150、B200、B300 分别为 50/50、75/75、100/100、150/150。B 方案先从 limma 全表中限制到 BING 且 FDR<0.05 的基因，再按 FDR、|logFC| 和基因符号固定顺序。

## 结果

共生成 28,566 条签名级评分和 22,290 条条件级结果。排名比较见 `results/ranking_comparison.csv`，分数分布和稳定性图见 figures。WTCS 越负代表表达关联方向上的逆转信号更强，不是药效更好的证明。

复现核验按 Signature ID 逐条比较 4,761 条历史 A 方案与新计算的 A_original：WTCS 最大绝对差为 5.82×10⁻¹⁴。历史 B 与新计算的 B200 最大绝对差为 6.65×10⁻¹⁴；所有 ID 均匹配，差异均未超过 1×10⁻¹⁰。明细见 `results/historical_reproduction_check.csv`。

## 可复现性与限制

输入路径、SHA-256、参数及缺失签名记录在 `results/run_manifest.json`。基因背景使用 GCTX 中成功映射的唯一 BING 符号，并在各方案间固定。历史 S1、S2 和冒烟测试文件仅作读取。本实验没有使用随机数据。
