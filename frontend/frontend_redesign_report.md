1. 建立 Apple-inspired 中性灰白、低饱和蓝色强调的全局视觉 Token，移除 Google Fonts 外链并改为系统字体。
2. 接入 Ant Design 简体中文 locale 与一致的表格、按钮、卡片、表单、弹窗主题；为普通状态和运行类型增加中文显示映射，底层 API 值保持原样。
3. 重做左侧导航/顶栏节奏；移动端改用抽屉导航，保留项目选择、新建项目和数据上传。
4. 统一卡片留白、标题层级、指标字号、表格行悬停、焦点环、加载动画和减少动态效果。
5. 统一 ECharts 图表字体、颜色、Tooltip 和动画；不改变数据或任何统计逻辑。
6. 将知识图谱主体调整为桌面三列工作区：筛选、Cytoscape 画布、节点详情；窄屏纵向排布。保留原搜索、筛选、缩放/拖动、路径高亮和证据查看逻辑。
7. `/compare` 更名为“可靠性分析”，增加真实 Exp006–Exp011 报告卡片，并保留原来的同项目运行比较功能。原始报告复制到 `public/reliability/` 供浏览器阅读；复制不改变原实验文件。
8. 最终结果页把报告中英文 protocol/caveat 转成中文 UI 说明；Final05 的审计结论、候选顺序、分数与边界信息仍来自原真实数据。
