# 项目级 S2 跨剂量稳定性摘要

日期：2026-11-14

## 实现内容

新增 `GET /api/v1/projects/{project_id}/s2/stability?top_n=10`，只读取当前项目最近一次已完成 S2 AnalysisRun 的条件结果。数据库模式按项目 ID 和运行 ID 过滤；旧版 CSV 模式先验证条件汇总文件 SHA-256。

输出按细胞系、扰动类型、处理时间和药物分组，列出剂量/条件数、进入 Top N 的条件数与比例、条件内最佳/最差名次及名次范围。不同时间不混在同组；WTCS 不跨剂量合并，也不产生单一药物总排名。该结果是排名复现的描述性指标，不表示药物疗效。

S2 页面已加入“跨剂量排名复现情况”表，并将各剂量 WTCS 条件表独立保留。页面明确显示稳定性不是药效总排名。

## 验收

- 纯函数测试覆盖剂量分层、Top N 复现比例、不同时间隔离、空药物 ID 与非法 Top N。
- 项目 API 测试以版本化 S2 条件记录验证读取来源、剂量计数、Top N 复现计算及项目隔离。
- 本轮相关测试：3 项通过。
- 前端 `npm run build` 通过。

本实现新增的是解释性稳定性摘要，不更改历史 S2 结果、Exp006–Exp011 候选排名或原始数据。
