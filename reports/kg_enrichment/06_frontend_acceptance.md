# Phase 6 frontend acceptance (partial)

The Top 10 mechanism view queries the read-only `top10/mechanism-reports/{pert_id}` endpoint for the selected frozen candidate. It displays rule-based evidence dimensions, signed regulatory paths with direction/evidence references, context-only ChEMBL/Reactome routes, and S1 terminal response when an exact gene-level match exists. Source evidence/PMID links are shown separately; S1 mRNA is labeled as transcript response and not protein activity. The report query is candidate-scoped and uses TanStack Query caching; it does not scan Neo4j.

Acceptance evidence: Frontend TypeScript and Vite production build passed (`npm run build`, 1m12s); Vite reported a >500 kB chunk-size advisory. The page uses the project-scoped mechanism-report API and hash-verified deterministic dossier; it does not scan Neo4j per request. The full KG suite passed (50 tests) and the targeted backend enrichment/registration/rollback suite passed (9 tests); two additional frozen-candidate/project-scoping API checks also passed. A broader legacy `tests/test_api.py` run completed 8 checks before the runner stalled; it is not counted as passing. SIGNOR/OmniPath and Reactome/PrimeKG GraphBuild layers are imported and audited in isolated staging. Reactome membership is present in offline dossier annotations; PrimeKG remains an unsigned association layer and is not used in signed mechanism paths or scoring. No browser E2E or screenshot was captured.
